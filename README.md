# 月亮流沙V2：蒙尘之罪 (Moon Sand V2)

> **作者**：崽崽  
> **开源地址**：https://github.com/JimmyBeck/Moon-Sand  

月亮流沙是一个运行在网页端的三维重力粒子与珠宝流体物理仿真作品。它解决了传统 WebGL 流体模拟计算卡顿、粒子穿模以及视觉单调的痛点，通过高度场烘焙和切向导流力学，在浏览器里实现了数万颗流沙粒子与宏观珠宝实体的平滑倾泻和碰撞。

---

## 3 步快速启动

前置环境仅需安装 **Node.js (>= 18)**。

```bash
# 1. 安装项目依赖
npm install

# 2. 启动本地开发服务
npm run dev

# 3. 浏览器访问终端给出的本地地址（如 http://localhost:5173）
```

---

## 核心功能与亮点

- **双物料混合物理模拟**：微观流沙与宏观珠宝（浮雕金币、双切工宝石、珍珠）协同倾泻，具备独立的质量、流速与表面滚动表现。
- **8 种内置经典承接物**：
  - 🏛️ 月下阶梯拱券
  - 🫴 月下捧金（双手捧月微曲面掌心）
  - 🌸 探云落玉（散掌多曲面接流）
  - 🏛️ 罗马长廊
  - 👑 蒙尘之罪（高脚金樽）
  - ⏳ 双曲沙漏
  - 🍷 独酌孤杯
  - 📁 外部自定义 OBJ 模型
- **外部 3D 模型即时导入**：直接将 `.obj` 格式文件拖拽入网页，系统自动烘焙高度场并完成物理碰撞承接。
- **纯黑 / 纯白双主题自适应**：
  - 纯黑模式：粒子辉光叠加，凸显夜色与流金质感。
  - 纯白模式：透明对比混合与文字自动反色，呈现如水墨细沙般的质感。
- **独立参数控制面板**：右侧抽屉式面板支持自选主副粒子颜色、流速、粒子数量、阻挡物尺寸与朝向角度，调整即时生效。
